## 2. 🔴 连线清单**手写**，不从 `prd.json` 推导

**PRD 是需求视角、连线是界面视角** —— 硬凑坏两边语义。

不画线的关系统统要**显式登记理由**（就地 / 外部 / 落点）。
校验：**「无出链集合 == 登记集合」**（现算）。

---

## 3. 🔴 正交 A* 路由

```
CELL = 14      # 网格
TURN = 9       # 转弯罚分 ← 不设会锯齿
CLEAR = 20     # 障碍外扩
```

元素 → 卡片边界用**直线 stub**；**只有 stub 允许落在源/目标卡片内**。

---

## 4. 🔴🔴 矩形约定（最大坑，同类错误犯了**三次**）

| 写法 | 谁用 |
|---|---|
| `(x, y, w, h)` | 排版、`element-map`、`_probe` 的 card、`_edge_point`、`l_connect`、`Router.__init__` 入参 |
| `(x0,y0,x1,y1)` 角点 | `Router` 内部 `obstacles/inflated/free`、`seg_rect_hit`、`_hits`、`_hits_any`、`place_label` 的 obstacles |

**混用不报错**，只让框**悄悄变矮变窄**（`240` 是宽、也是「x 到 240」），
于是「不压卡片」全绿**而其实在压**。

- **转换只允许在函数入口做。**
- **防复发断言**：「每个元素矩形都落在自己卡片的矩形里」
  —— 元素坐标由百分比现算、卡片坐标来自排版，**两个量独立，约定搞反立刻炸**。

---

## 5. 🔴 三条硬规则

### ① `_probe` 撞上别人的卡片必须作废

**不能绕过去继续往外找** —— 卡片紧挨着排，主态与补态只隔 14px；
继续走会在**邻居另一侧**取到空位，引出段**横穿邻居**。

作废后由 `route()` **换边重试**（`side` 只是首选，不是唯一）。

### ② 同卡两元素贴在一起时绕一道

间隙 **0~2.5px** 时直肘两拐点重合 → 整条线**退化成一个点**
（画面上什么都没有，**数据源里它还在**）。

`l_connect` 在 `hsep/vsep < 26` 时**绕一道**。

### ③ 标签两级，交互方式**不能退**

1. 「交互方式 + 业务标签」
2. 放不下退成**只写交互方式** —— **交互方式不能退**（那是这条线唯一的信息）

标签要**压在自己那条线上**（相切也算），可**垂直于线错开一档** `h2 = text_h/2 + pad`
（同行相邻两组控件的肘线共线，不错开永远有一个放不下）。

**同卡标签允许落在自己这张卡里，但不许碰别的卡** —— 依据数据源的 `labelInCard`，**不是「看它压没压」**。

## 6. 校验要点（`check-anno.py`）

| # | 查什么 |
|---|---|
| ① | **闭环**：同屏 id 唯一 / 起终点在 `element-map` / 需求号在 PRD / 无出链登记不多不少 |
| ② | **逐段与所有卡片求交**（仅 stub 允许碰自己的卡）+ 可见长度 ≥ 8px 且无零长段 |
| ③ | **最小间距 ≥ 11.5px** |
| ④ | 标签不压卡片 / 不重叠 / 压在自己线上 / **每条线都带交互方式文字** |
| ⑤ | 计数**现算** |
| ⑥ | **视图不漂移**（HTML 里 polyline 顶点与 JSON **逐字比对**） |
| ⑦ | **变异测试两条**（直线连接 / 抹掉障碍）都必须变红 |

### 实测基线

世界 **3030×4075** · 卡片 **25** · 交互点 **148**（累计 **163**）· 连线 **42 条**（跨端 17）·
标签 **42/42** · 最小间距 **20.9px** · **9.6MB**
