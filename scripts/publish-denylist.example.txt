# 项目词黑名单 —— 模板（复制为 publish-denylist.txt 后填写）
# ============================================================
#  用途：防止「工作流产出的内容」混进要发布的工作流本体。
#
#  常规自检（check-publish-safe.py 内置规则）只扫：
#      密钥 / API Key / 本机绝对路径 / 手机号 / 身份证 / 邮箱
#  它**扫不到商业 know-how** —— 真实阈值、分成比例、付款通道、
#  合作方名称、内部文档名、客户人名。
#
#  这类内容泄露的后果比一个手机号严重得多，而且**常规规则一个都抓不到**。
#  所以需要你按自己的项目维护这份名单。
#
#  格式：一行一个词，# 开头是注释。子串匹配、大小写不敏感、BLOCK 级。
#
#  ⚠️ 填好后请确认它已被 .gitignore 排除（默认已排除）——
#     这份名单本身列的就是敏感词，不能发出去。
# ============================================================
